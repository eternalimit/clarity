## Abstract

The test codes a six-feature evidence/state mechanism specification, based on a September 24 TCGE source composite, against five earlier independent control families and five published OpenAI announcements dated September 8 through October 7, 2026. Identity labels were hidden from the arithmetic scoring function, but the same research assistant knew their identities while interpreting and coding source documents. Consequently, the evaluation is a **masked-label deterministic scoring check, not a blinded independent reviewer experiment**. Across eleven scored source composites, exactly one—the TCGE definition deliberately assembled from four September source files—meets all six prespecified features by construction. No examined OpenAI *public release description* does. Older pre-2026 sources substantiate several isolated features; their highest broad five-feature score was 3, exceeding the best OpenAI description's 2. An independently attributable TCGE→OpenAI transfer pathway was not recovered. The evidence neither proves influence nor establishes the absolute absence of influence; claims requiring inaccessible internal artifacts remain unresolved.

## 2. Frozen, prespecified mechanism criteria

From separately committed protocol \`5d3a4e...\`, each feature is 1 only when **explicitly supported by the inspected document** and 0 otherwise, where 0 means **not established by inspected document**, not proven absent from inaccessible underlying software:

- F1: Explicit third verification state neither true nor false.
- F2: Permission/authorization distinguished from execution action.
- F3: Retained, inspectable provenance or research history.
- F4: Separately executable verification check for a specified outcome; does **not** by itself guarantee organizational independence.
- F5: Historical falsifications/negative evidence explicitly persist.
- F6: Exact conjunctive R AND I AND independently validated E knowledge admission, or a formally proved equivalent typed rule.

The \`broad\` score is \`sum(F1..F5)\` and ranges from 0 to 5. \`full\` requires all six booleans; \`causal\` also requires separately verified transfer. Scores are **manual documentary feature annotations**, not objective source-code equivalence, probability, model weights, or statistical significance.

The TCGE "positive" category is a **composite of four separate source documents**, while controls/targets are mainly individual publications. This asymmetry inflates its coverage and means a 5/5 broad positive score is expected by construction. Do not treat the comparison as proof of novelty, superior accuracy, or unique scientific mechanisms.

### Reproduction of the actual masked deterministic scoring operation

The scorer used **only masked IDs, feature vectors, and binary transfer flags**. Source names were reattached afterward. This code reproduces the integer logic and assertions:

\`\`\`javascript
const data = {
  D01:"000000", D02:"100000", D03:"000000",
  D04:"011100", D05:"010000", D06:"001000",
  D07:"001100", D08:"111111", D09:"001100",
  D10:"001100", D11:"010000"
};
const transfer = Object.fromEntries(Object.keys(data).map(k=>[k,0]));
const rows = Object.entries(data).sort().map(([id,s])=>{
  const bits=[...s].map(Number);
  return {id, broad:bits.slice(0,5).reduce((a,b)=>a+b,0),
          full:Number(bits.every(Boolean)),
          causal:Number(bits.every(Boolean) && transfer[id]===1)};
});
if(rows.length!==11)throw Error("wrong row count");
if(rows.filter(x=>x.full).map(x=>x.id).join()!=="D08")throw Error("full-match discrepancy");
if(rows.some(x=>x.causal!==0))throw Error("unverified causal promotion");
console.log(rows);
\`\`\`

**Independence caveat:** Label masking to a deterministic calculator is not blinding the human who assigned the input features. There was no independent second coder, no preregistered control-corpus selection before this conversation, and no external witness. Hence no causal proof or statistically meaningful blind-test efficacy is asserted. Source URLs currently hosted by OpenAI and other publishers were read on Oct 10 but exact historical HTML response bytes were not cryptographically frozen; their content may change after this audit.
