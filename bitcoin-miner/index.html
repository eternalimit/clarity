What counts as success

This app never treats process output, a local hash, or a GitHub workflow as proof that Bitcoin was mined. A block claim requires a real Bitcoin block hash and independent network lookup.

Run locally with real hardware

Set BTC_MINER_COMMAND on the machine connected to your miner, then run python3 bitcoin-miner/controller.py.

After a real block candidate is accepted, verify it with python3 bitcoin-miner/verify_receipt.py --block-hash <64-hex-block-hash>.
